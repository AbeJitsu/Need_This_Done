Owner: engineering; scope: application dependencies; removal target: before production promotion. Remote push, production release, and hosted cleanup remain separate approval boundaries.

Google Calendar can remain manual for the first pilot, but the OAuth-state repair and controlled test must pass before public Calendar booking or automatic reminders are claimed.

**No-broken-windows policy:** Every warning, failing check, stale route or document, broken interaction, and unresolved TODO is a defect. Fix it in the current slice, or record an owner-approved exception here with scope and removal date. An open exception blocks production promotion.
