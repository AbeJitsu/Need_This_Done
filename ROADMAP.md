# NeedThisDone Roadmap

## Finish line

Deliver one paid outcome from each human-led public offer:

| Offer | Proof |
| --- | --- |
| Website Fix | One contained $500 engagement is scoped, manually invoiced, delivered, and handed off. |
| Managed Automation | One proposal-based 30-day pilot completes four human-led weekly briefs and records outcomes. |

## Next outcomes

1. Preserve the current Daily Desk work as a clearly labelled private
   experiment, not a product-direction claim.
2. Extract a reusable owner-approved orchestration core for tasks, decisions,
   cost, results, signing, and stopping work.
3. Consolidate private operator views around that core while retaining the
   public Website Fix and Managed Automation experience.
4. Validate the resulting local candidate before asking for any hosted,
   provider, or Mac-runtime approval.

## Later, only under a new approval

- Hosted migration, deployment, secret provisioning, provider activation, or
  Mac runtime activation.
- External email, publishing, spend, or customer-facing automation.
- Any expansion of the assistant's tool authority or public surface.
